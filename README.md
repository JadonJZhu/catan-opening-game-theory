# Where to Settle First: the Catan Opening as a Two-Player Zero-Sum Game

A game-theory course project (MATH 167). We model the two-player *Catan* opening on the beginner board as a zero-sum snake draft (P1, P2, P2, P1) over four kinds of settlement spot, find all of its Nash equilibria, and select the subgame-perfect one.

- **Paper:** [`paper/main.pdf`](paper/main.pdf)
- **Interactive web app:** <https://jadonjzhu.github.io/catan-opening-game-theory/webapp/>

| Path | What it is |
|---|---|
| `analysis/` | Python: `board.py` (board and ports), `model.py` (hand values, the draft, the all-NE check, the exact 54-spot solve), `run_all.py` (runs everything) |
| `data/` | `board.json`, `results.json` (baseline results), `sensitivity.json` (442-setting parameter grid) |
| `figures/` | All figures, generated by `run_all.py` |
| `paper/` | `main.tex` → `main.pdf`. `tables.tex` is generated by `run_all.py`. |
| `webapp/` | The interactive explorer. Open `index.html` directly; `node test.mjs` checks it against the Python output. |

## Reproduce

```sh
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cd analysis && ../.venv/bin/python run_all.py      # ~4 min; --reuse-grid skips the parameter grid
cd ../paper && latexmk -pdf main.tex
cd ../webapp && node test.mjs
```
